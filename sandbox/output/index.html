BoringAvatarsSharp

Six styles, four names, and eight reference palettes in round and square outlines.

Compare names · Compare palettes

Each image is a separate SVG document. Select an image to open its SVG file.

Usage

string svg = AvatarGenerator.GetSvg(
    "Ada Lovelace", AvatarVariant.Beam, size: 88,
    square: true, includeTitle: true,
    colors: [0x7C3F58, 0xEB6B6F, 0xF9A875, 0xFFF6D3]);

This example uses Ice Cream GB; see its source below.

Palettes

Every image below uses Ada Lovelace. Each palette is shown with square: false and square: true. Omit colors for the default palette. Beam uses black or white facial features for contrast.

These palettes are references for choosing your own colors values. The library includes only its default colors; the other palettes are defined in this sample.

Every color in a palette is eligible; colors after the fifth entry are used too. Selections can repeat: Marble makes 3 palette selections, Beam 2 (plus black or white facial features), Pixel 64, Sunset 4 gradient stops, Ring 5, and Bauhaus 4. A larger palette adds variety across names, but not every color will appear in each image. Gradients and blending can produce intermediate colors.

BoringAvatars and Nord use the MIT license; ColorBrewer uses Apache 2.0. The Ice Cream GB listing credits Kerrie Lake but does not specify a separate license. See palette credits and licenses.
